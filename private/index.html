Link ergänzen

Deine Sammlung, editierbar.

Die neue Oberfläche funktioniert sofort mit allen bestehenden Links. Für geräteübergreifende Änderungen richtest du einmal Supabase ein.

  1. Supabase-Projekt erstellen. Unter Authentication → Users deinen Benutzer mit E-Mail und Passwort anlegen. Öffentliche Registrierungen deaktivieren.
  2. Die Benutzer-UUID unten eintragen, das SQL herunterladen und im Supabase SQL Editor ausführen. Es legt eigene Tabellen, die 29 ursprünglichen Links und die Schreibrechte nur für diese UUID an.
  3. In dieser HTML-Datei bei SUPABASE_URL und SUPABASE_KEY die Projekt-URL und den Publishable Key (alternativ Legacy-Anon-Key) eintragen. Keinen Secret- oder Service-Role-Key verwenden.
  4. Die Datei auf deiner bestehenden Website ersetzen und über HTTPS öffnen. Danach mit „Anmelden“ bearbeiten.

Sichtbarkeit: Die Links bleiben öffentlich lesbar, einschliesslich der bisherigen Passwort-Hinweise. Das Login schützt ausschliesslich das Bearbeiten.
