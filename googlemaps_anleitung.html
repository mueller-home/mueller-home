🗺 Google Maps API einrichten

Anleitung für Annette & Patrick · Dauer: ca. 15–20 Minuten

Diese Anleitung zeigt euch wie ihr einen Google Maps API-Key erstellt. Dieser wird für die Karte und die Standortsuche auf dem StaffKeeping-Marktplatz benötigt. Den fertigen Key einfach an Chris weitergeben — den Rest erledigt er.
1
Google Cloud Account erstellen

Geht auf console.cloud.google.com und meldet euch mit einem Google-Konto an. Falls noch keines vorhanden ist, zuerst ein Google-Konto erstellen.

Klickt oben auf «Projekt erstellen», gebt als Name StaffKeeping ein und bestätigt.

⚠ Google verlangt eine Kreditkarte zur Verifikation. Es entstehen keine Kosten solange das Nutzungslimit nicht überschritten wird — für StaffKeeping bleibt der Betrieb voraussichtlich dauerhaft im kostenlosen Kontingent (USD 200 Gratisguthaben pro Monat).
2
Maps JavaScript API aktivieren

Im linken Menü auf «APIs & Dienste» → «Bibliothek» klicken.

Nach «Maps JavaScript API» suchen → anklicken → «Aktivieren».

Danach dasselbe für «Places API» — auch aktivieren.

💡 Beide APIs werden benötigt: Maps JavaScript API für die Karte, Places API für die PLZ/Ort-Suche.
3
API-Key erstellen

Im linken Menü auf «APIs & Dienste» → «Anmeldedaten» klicken.

Oben auf «+ Anmeldedaten erstellen» → «API-Schlüssel».

Den angezeigten Key sofort kopieren und sicher ablegen.

🔒 Den Key bitte per WhatsApp oder Signal an Chris weiterschicken — nicht per E-Mail, da Keys nicht unverschlüsselt verschickt werden sollten.
4
Key einschränken (empfohlen)

Klickt auf den neu erstellten Key um ihn zu bearbeiten.

Unter «API-Einschränkungen» wählt «Schlüssel einschränken» und wählt nur die zwei aktivierten APIs aus: Maps JavaScript API und Places API.

Unter «Anwendungseinschränkungen» kann später die Domain von StaffKeeping eingetragen werden — das machen wir wenn die App live ist.

🔒 Einschränkungen verhindern, dass der Key von Dritten missbraucht werden kann.
