# Benutzerhandbuch und Bildmaterial

`Benutzerhandbuch.md` enthält den vollständigen, nach Arbeitsabläufen gegliederten Text. `SCREENSHOTS.md` enthält die redaktionellen Bildaufträge. Die zentrale Handbuchverwaltung wird über die mitgelieferte SQL-Migration aktualisiert.
