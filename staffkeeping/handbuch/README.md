# Benutzerhandbuch: Workflow-Fassung

Die veröffentlichten Benutzerkapitel in Supabase sind entlang der tatsächlichen Arbeitsabläufe sortiert. Ältere Kapitel mit technischen Versionsbezeichnungen oder SK-Nummern werden durch die Migration nicht gelöscht, sondern in den Entwurfsstatus versetzt. Dadurch verschwinden sie für Mitglieder aus «Hilfe» und «Hilfe zur Seite». Administratoren können sie weiterhin prüfen. 

**Wichtig:** Nach Ausführung der Migration die Hilfe neu laden und die Einträge im Administrationsbereich kontrollieren. Die 13 aktuellen Kapitel sollten in der festgelegten Reihenfolge erscheinen. Einzelne redaktionell eigens angelegte öffentliche Kapitel müssen bei Bedarf in einen aktuellen Workflow übernommen werden, bevor sie wieder veröffentlicht werden.
