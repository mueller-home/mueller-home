🗺 Google Maps Geocoding API aktivieren

Ergänzung zur bestehenden Google Maps Anleitung · Dauer: ca. 10 Minuten

Diese Anleitung ist eine Ergänzung zur bestehenden Google Maps Anleitung. Die Geocoding API wird zusätzlich benötigt damit StaffKeeping Adressen (PLZ + Ort) automatisch in GPS-Koordinaten umwandeln kann — Grundlage für die Umkreissuche auf dem Marktplatz. Bitte dieselbe Google Cloud Console und dasselbe Projekt wie bei der bisherigen Einrichtung verwenden.
1
Google Cloud Console öffnen

Geht auf console.cloud.google.com und meldet euch mit demselben Google-Konto an wie bei der bisherigen Einrichtung.

Sicherstellen dass das richtige Projekt ausgewählt ist — oben links den Projektnamen prüfen (StaffKeeping oder der bei der Ersteinrichtung gewählte Name).

2
Zusätzliche APIs aktivieren

Im linken Menü auf «APIs & Dienste» → «Bibliothek» klicken.

Folgende APIs nacheinander suchen und jeweils auf «Aktivieren» klicken:

📍
Geocoding APIPflicht — wandelt Adressen in GPS-Koordinaten um (Standortsuche)
🔍
Places APIFalls noch nicht aktiviert — für zukünftige Autocomplete-Funktion
🗺️
Maps JavaScript APIFalls noch nicht aktiviert — für die Karte auf dem Marktplatz
💡 APIs die bereits aktiviert sind zeigen «Verwalten» statt «Aktivieren» — diese können so belassen werden.
3
API-Key-Einschränkungen prüfen

Im linken Menü auf «APIs & Dienste» → «Anmeldedaten» klicken.

Den bestehenden API-Key anklicken und unter «API-Einschränkungen» prüfen:

  • Falls «Schlüssel nicht einschränken» gewählt ist → nichts ändern, der Key funktioniert für alle APIs.
  • Falls bestimmte APIs explizit aufgelistet sind → sicherstellen dass Geocoding API in der Liste enthalten ist. Falls nicht: hinzufügen und speichern.
⚠ Wenn der Key eingeschränkt ist und die Geocoding API fehlt, funktioniert die Standortsuche nicht. Nach dem Ändern bitte speichern.
4
Kosten im Überblick

Zur Information — bei StaffKeeping im MVP-Betrieb entstehen voraussichtlich keine zusätzlichen Kosten:

  • Geocoding API: $5 pro 1’000 Anfragen → bei 200 Registrierungen ca. $1
  • Places API: erst relevant wenn Autocomplete eingebaut ist
  • Maps JavaScript API: $7 pro 1’000 Kartenaufrufe
✓ Das monatliche Google-Gratisguthaben von $200 deckt den gesamten MVP-Betrieb problemlos ab.
5
Fertig — Chris informieren

Sobald die Geocoding API aktiviert ist und die Key-Einschränkungen geprüft sind, bitte Chris kurz informieren.

Chris trägt den bestehenden Key dann in die Bubble-App ein — ihr müsst keinen neuen Key erstellen.

🔒 Den Key bitte sicher übermitteln — nicht per E-Mail im Klartext.
