1. Projektübersicht

B2B-Marktplatz für temporären Personalaustausch in der Hospitality-Branche (Hotel/Gastro/Camping) im DACH-Raum. Keine Gewinnerzielungsabsicht durch die Vermittlung. Betriebe können Inserate aufschalten (Biete/Suche) und direkt miteinander chatten. Chris Müller (Christophe Müller) ist der Entwickler, Annette Krey Solutions ist der Auftraggeber.

6. Bewertungssystem (Stand 05.06.2026)

  • popup-review auf my-listings: Sternebewertung (Kommunikation + Zuverlässigkeit), Weiterempfehlung, Kommentar
  • Custom State is_view_mode (yes/no) auf popup-review: no = editierbar, yes = read-only
  • btn-vergeben-review / btn-partner-review: sichtbar wenn count = 0. Default unsichtbar. Collapse when hidden: on
  • btn-vergeben-review-view / btn-partner-review-view: sichtbar wenn count > 0. Öffnet Popup in View-Modus
  • Gegenseitige Bewertung: review-submit-btn Workflow aufgeteilt in zwei Schritte mit «Only when»-Condition: Inserent bewertet Partner (reviewed = partner_business), Partner bewertet Inserenten (reviewed = business)
  • popup-business-reviews auf listing-detail: Type Listing. Zeigt Zusammenfassung (Kommunikation, Zuverlässigkeit, Weiterempfehlung, Anzahl) + Kommentarliste. Constraint: reviewed = Current page's Listing's business. Aufruf via Link «★ Bewertungen anzeigen» beim Betriebsnamen (nur sichtbar wenn Bewertungen vorhanden)
  • re-business-reviews: Reusable Element, Type User. Gleiche Struktur wie popup-business-reviews. Verwendet auf Seite my-reviews.
  • Seite my-reviews: Neue Seite «Meine Bewertungen» in Sidebar. Zeigt erhaltene Bewertungen des eingeloggten Benutzers via re-business-reviews.
  • Noch offen: Bewertungs-Button nur nach Inserat-Ende · popup-business-reviews durch re-business-reviews ersetzen (nicht dringend)

9. Wichtige Bubble-Eigenheiten

  • Typ-Inkompatibilitäten → Constraint entfernen statt workaround
  • Option Sets bei Dropdowns, Workflows, Privacy Rules und Display-Elementen überall aktualisieren wenn Felder konvertiert werden
  • «Parent group's thing» = generischer Typ wenn Parent group keinen spezifischen Typ hat — dann Typ setzen
  • Custom States im Preview bleiben manchmal hängen → Hard Refresh (Ctrl+Shift+R)
  • Workflow-Reihenfolge wichtig: State setzen VOR Show Popup wenn Conditionals beim Öffnen evaluiert werden
  • Collapse when hidden aktivieren wenn zwei alternative Buttons nebeneinander stehen
  • Inbox-Sortierung: last_message_date descending auf Conversation
  • Land Option Set hat Attribut code (CH/DE/AT)
